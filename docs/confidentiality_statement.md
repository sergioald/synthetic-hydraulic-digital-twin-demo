# Confidentiality Statement

This repository is a synthetic public demonstration of applied-AI and digital-twin workflows for sensor-heavy hydraulic systems.

It does **not** contain real FastBlade data, University of Edinburgh code, partner data, proprietary control logic, facility-specific parameters, industrial reports, real hydraulic measurements, real audio signals, real database schemas or confidential information.

All datasets, signals, parameters and operating behaviours in this repository are generated synthetically by code. Any similarity to real systems is illustrative and non-operational.

## Publication boundary

The repository may include:

- synthetic time-series data generated from public assumptions
- generic hydraulic-system variable names
- illustrative operating states and anomaly labels
- reproducible Python workflows
- tests, documentation and example reports based only on synthetic data

The repository must not include:

- real FastBlade diagrams or images
- real University of Edinburgh code
- real sensor exports
- real operating parameters
- partner-specific requirements or reports
- proprietary control logic
- facility-specific layouts
- real acoustic/audio measurements
- confidential database schemas
- material copied from internal documents

## Intended use

The purpose of this repository is to demonstrate research-software practice, applied-AI workflows, digital-twin thinking, sensor validation, anomaly detection and energy-analysis methods without exposing private or confidential work.
