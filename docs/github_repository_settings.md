## Repository visibility note

The repository should remain clear that it uses fully synthetic data. Avoid
descriptions that imply:

- real FastBlade data;
- operational monitoring deployment;
- validated fault diagnosis;
- proprietary facility reproduction;
- safety-critical digital-twin readiness.
